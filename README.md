# Expense Tracker Web Application

## Overview

A full-stack web application to help users track and manage personal expenses efficiently.

## Features

- User authentication and authorization.
- Add, edit, and delete expenses.
- View expenses in a list with pagination.
- Interactive charts to visualize expenses by category and over time.
- Responsive design using Bootstrap.

## Technologies Used

- **Backend:** Python, Flask, SQLAlchemy
- **Frontend:** HTML, CSS, Bootstrap, JavaScript, Chart.js
- **Database:** SQLite
- **Authentication:** Flask-Login, Flask-WTF
- **Testing:** Pytest
